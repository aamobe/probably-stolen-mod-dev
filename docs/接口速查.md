# 深空当铺接口速查

基础速查来自官方仓库 `ae161038`。读档事件已按本机 100-Rev13 程序集核对。官方 `3541332` 的 1.0.0.14 测试分支新增接口单独列在下文。其余条目按官方示例索引，具体签名以目标游戏程序集为准。

已知方法名查 [接口符号索引](接口符号索引.md)；动手前读 [高频接口开发卡](接口开发卡.md)。

## 生命周期与状态边界

| 时机 | 可以做什么 | 限制 |
| --- | --- | --- |
| IMod.Init(ModManifest manifest) | 保存 manifest、创建 ModLog、定义配置 | 主菜单阶段，不能依赖局内对象或存档 |
| IMod.OnEnable() | 注册 ModHook、选项、升级、调试入口 | 资源尚未全部加载；订阅与清理成对 |
| ModHook.OnModAssetsLoaded(LoadedMod mod) | 使用已加载的资源 | 为每个 Mod 触发，先过滤 mod.Manifest.ID |
| ModHook.OnGameLoadedInit | 读取本局 Mod 数据 | 在此之前 GetModData 返回回退值，写入无效 |
| ModHook.OnGameLoadedNormal | 创建场景 UI、绑定本局状态 | 在本机 100-Rev13 中早于库存解码；切场景后清理旧引用 |
| IMod.OnDisable() | 解除订阅、释放自己创建的资源 | 菜单停用下次启动生效，不假定立即回调；停止行为另查官方后台章节 |

## 读档事件签名

本机 `PlayerStore.VERSION_NUMBER` 为 `VERSION 100-Rev13`，Steam Build ID 为 `26525552`。已反编译本机 `Assembly-CSharp.dll` 中的 `ModHook` 声明和 `PlayerStore.LoadGame` 调用点。

| 事件 | 委托类型 | 本机 `PlayerStore.LoadGame` 中的触发位置 |
| --- | --- | --- |
| `ModHook.OnGameLoadedInit` | `System.Action` | 通过前置存档文件检查后，`ES3.LoadInto("playerStore", ...)` 之前。官方说明从该阶段起可通过 `ModHelper.GetModData` 读取 Mod 自己的存档数据。 |
| `ModHook.OnGameLoadedEarly` | `System.Action` | `playerStore` 载入并应用难度后，读取总游玩时间前。 |
| `ModHook.OnGameLoadedNormal` | `System.Action` | 场景与店铺状态初始化中，第一批库存解码前。 |
| `ModHook.OnGameLoadedLate` | `System.Action` | 库存解码调用及许可证重应用等处理之后，接近 `LoadGame` 尾部。 |

四个事件均为 `public static event`，处理函数形如 `void OnLoaded()`，启用时订阅，停用时用同一委托解除。事件本身不传递存档对象或成功标志。依赖库存的操作还需核对当前会话与实际恢复结果，尤其是需要在成功恢复后发放物品或结算的功能。 [官方存档说明](https://github.com/dragonpan2/probably-stolen-modding/blob/ae161038c6cfed6725f66cfbc5d6b05406975068/ModdingGuide.zh-CN.md#保存模组数据) · [库存恢复验证场景](框架与维护接口.md#验证场景)

## 版本差异

### 1.0.0.14 测试分支新增接口

下列入口由官方 100-Rev14 测试分支文档引入。本机 100-Rev13 的 `ModHelper` 和 `ModHook` 声明未见这些新增成员。使用它们的工程应引用对应的测试分支程序集，并在支持该分支的环境中验证。

| 功能 | 新增入口 | 接入限制 |
| --- | --- | --- |
| 游戏版本 | `ModHelper.GetGameVersion`、`ModHelper.IsGameVersionAtLeast`、`ModHelper.GameVersionMatches` | 分别读取点分版本、比较最低版本、按清单规则判断匹配。 [官方游戏版本](https://github.com/dragonpan2/probably-stolen-modding/blob/3541332ad755a07e423077659863268256ccd233/ModdingGuide.zh-CN.md#游戏版本) |
| 游戏结局 | `ModHelper.AddEnding`、`ModHelper.TriggerEnding`、`ModHelper.RemoveEndings`、`ModHelper.GetEndingIds`、`ModHelper.IsGameOver`、`ModHook.OnGameOver` | 结局用稳定 ID，触发在主线程，事件参数为结局 ID。 [官方游戏结局](https://github.com/dragonpan2/probably-stolen-modding/blob/3541332ad755a07e423077659863268256ccd233/ModdingGuide.zh-CN.md#游戏结局) |
| F9 调试面板 | `ModHelper.AddDebugPanel`、`ModHelper.RemoveDebugPanel`、`ModHelper.OpenDebugPanel` | 需要开发工具；用现有的调试按钮 API 填充分类，移除本 Mod 所有调试按钮时也会清理面板。 [官方调试入口](https://github.com/dragonpan2/probably-stolen-modding/blob/3541332ad755a07e423077659863268256ccd233/ModdingGuide.zh-CN.md#添加你自己的调试按钮) |
| 音频采样 | `ModHelper.LoadSoundSamples`、`ModHelper.IsSoundCompressed` | 用本 Mod 的声音键；压缩剪辑的 PCM 数据通过采样接口获取，回调在主线程执行。 [官方声音说明](https://github.com/dragonpan2/probably-stolen-modding/blob/3541332ad755a07e423077659863268256ccd233/ModdingGuide.zh-CN.md#声音) |
| 窗口与显示器 | `ModHelper.GetMonitors`、`ModHelper.GetWindowClientRect`、`ModHelper.SetWindowClientRect`、`ModHelper.SetWindowClientPosition`、`ModHelper.ReleaseWindow`、`ModHelper.IsWindowControlSupported` | Windows 玩家版本，移动和改尺寸限窗口模式，设置方法需要 `window` 能力。 [官方窗口与显示器](https://github.com/dragonpan2/probably-stolen-modding/blob/3541332ad755a07e423077659863268256ccd233/ModdingGuide.zh-CN.md#窗口与显示器) |

### 版本相关规则

| 项目 | 100-Rev13 基线 | 1.0.0.14 测试分支官方变更 |
| --- | --- | --- |
| `<GameVersions>` | 官方记录旧菜单以 `0.46D` 为匹配基准。 | 按真实点分版本匹配。支持前缀、通配前缀和闭区间；开放区间显示不匹配。旧 `0.46` / `0.46D` 条目不着色，匹配结果用于提示。 |
| 权限与扫描 | 旧快照记录了 12 月 10 日的能力政策计划。 | 更新记录撤回了工坊 `files` / `network` 的开发者验证要求，并细化了外部库补丁、反射和工具库的分类。Febucci 和 DOTween 列入免费目标。发布时按目标版本的扫描输出核对生效规则。 |
| 声音加载 | 沿用旧版声音资源接口。 | 大于或等于 1 MB 的 OGG、MP3 保持压缩，播放时解码。直接读 PCM 的功能需适配采样接口。 |
| F8 与外部链接 | 沿用旧版控制台字体与链接行为。 | F8 加入中日韩字符回退。撤回 `Application.OpenURL` 的运行时拦截，扫描规则仍适用。 |

规则来源为[官方 API 变更记录](https://github.com/dragonpan2/probably-stolen-modding/blob/3541332ad755a07e423077659863268256ccd233/APIChanges.zh-CN.md)。日期属于官方计划，生效状态以目标游戏版本为准。

## 使用顺序

先选上表的功能入口，读取完整官方章节，再核对目标程序集签名与 APIChanges；官方接口覆盖不了才定位游戏内部调用链。实现时记录注册时机、ID/资源归属、返回值与空值、释放方式和存档影响。已有 Mod 升级先保留其 ID、数据键和资源约定，不自动重建。
