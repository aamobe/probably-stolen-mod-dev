## 典型需求的静态查阅核对

| 需求 | 查到的入口 | 实现前可见的关键约束 |
| --- | --- | --- |
| 新物品和图片 | 速查 → 物品开发卡 → 官方钩子/资源章节 | 工厂注册、稳定 ID、主菜单与局内边界、资源就绪过滤 |
| 可购买升级 | AddNetworkUpgrade → 官方人脉升级 | 付款后回调、读档查询、重复购买、移除保留存档 |
| 新开局方案 | AddStartingScenario / RemoveStartingScenarios | onStart 不在读档运行、ID 稳定、窗口与局内时机 |
| 夜间地点 | AddAfterhourLocation → 地点开发卡 | 返回类型、共享背包流程、未知 ID 空值、事件叠加 |
| 鉴定物品 | AddAppraisalItem → 鉴定开发卡 | 生成时确定价格、估价读取稳定状态、移除原版替换需重启 |
| 配置与后台 | GetConfig / RunInBackground | 加载不触发 OnChanged、取消令牌、主线程回调、停止后不提交结果 |

这是文档检索与条文核对，不是运行模拟或游戏实测。脚本实际执行结果：原始快照哈希与清单一致，生成文件一致，324 个本地链接及目标锚点通过。后续若新增导航，链接数随之变化，以检查输出为准。

## 当前边界

用于高效定位官方接口和准备实现，达到文档层面的交付要求。尚未绑定具体 Mod；首次实现仍需填项目参数并核对目标游戏程序集签名。没有运行编译、扫描器、游戏，也没有部署或发布。外链在线状态及官方原始快照内部原有链接不在本地检查范围内。本轮公开仓库准备包含文档与维护工具；具体提交以 Git 历史为准。

## 发布前复核

新增官方来源固定提交下载与哈希校验；公开仓库排除官方全文和生成正文，保留官方链接及本地下载机制。新增接口卡依赖基线检查；链接数量因公开链接替换而变化，以当前脚本输出为准。
