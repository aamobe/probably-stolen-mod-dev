## 本套的范围

这是“深空当铺游戏级模板＋接口参考”，可为多个 Mod 复用；尚未绑定一个具体 Mod。AGENTS 中 <…> 是必须在实例化项目时填写的参数，不代表命令已经验证可运行。需填写 Mod 名称/ID、目标游戏版本、项目目录、工作目录、存档路径、stage、repo、baseline、版本来源及适用命令；无扫描脚本时使用官方 F8 mod-scan，不虚构本机脚本。

## 技术选择

正式版默认官方 IMod、Unity Mono、netstandard2.1；游戏 Managed 引用 Private=false。SDK 按官方入门为 6 或更高，具体工程如有 global.json 或其他约束按项目核对。官方生成器默认部署须在具体工程中改成显式授权部署。无权威版本来源时优先使用官方 manifest 的 ModVersion，再使其他元数据同步；已有项目保留自己的单一来源。

新项目优先官方 ModHook / ModHelper、CustomUIManager / PaperUI / MachineHelper。正式版前置 Mod 引用和联动能力优先官方途径，不继承旧反射联动限制。正式版资源规范与项目美术风格分开：旧项目尺寸或立绘倍率不作为官方 API 限制。
