# 高频接口开发卡

这些卡片归纳官方 ae161038 的调用约定，不是完整 C# 签名。参数名来自官方示例；没有声明返回类型的接口不据此猜测。完整代码见链接；引用符号可查 [符号索引](接口符号索引.md)。本套尚未与游戏程序集编译核对。

## 物品与资源

**入口**：在 OnEnable 用具名处理函数订阅 `ModHook.OnModItemDirectoryInit`，处理函数接收 `ModItemDirectory`，调用 `directory.Add(id, factory)`；具体工厂写法见 [物品注册](https://github.com/dragonpan2/probably-stolen-modding/blob/ae161038c6cfed6725f66cfbc5d6b05406975068/ModdingGuide.zh-CN.md#钩子点)。OnDisable 用同一处理函数解除订阅。ID 稳定且加 Mod 前缀。

**时机**：注册工厂与生成实例分开。主菜单不要访问本局商店或发货。`OnModAssetsLoaded(LoadedMod)` 为每个启用 Mod 触发，先筛选 `mod.Manifest.ID`；只有需要在启动阶段主动读取资源才等这个事件。工厂中的 `SetSpriteAndShapeFromMod` 用法按官方示例，不额外猜延时。

**检查场景**：新开局生成、存档后重载、资源缺失、同名资源与其他 Mod 共存。新物品实例由谁放入哪个库存必须明确，生成成功不等于交付成功。

## 存档与配置

**本局数据**：`ModHelper.SetModData(modId,key,value)` / `GetModData(modId,key,fallback)`，以及 Int/Float/Bool 辅助方法；从 OnGameLoadedInit 起读取，禁用保留数据。结构用 JSON 并保存模式版本；迁移保留已有内容、重复执行结果一致。物品自身的数据用 `ModifyTag / GetTagReadonly`，不要把所有物品状态塞进一个全局键。[完整说明](https://github.com/dragonpan2/probably-stolen-modding/blob/ae161038c6cfed6725f66cfbc5d6b05406975068/ModdingGuide.zh-CN.md#保存模组数据)

**跨存档偏好**：`ModHelper.GetConfig(modId)` 返回配置，`Define / DefineEnum` 返回 `ConfigEntry<T>`；定义后立即读 `Value`。`OnChanged` 不会在加载时触发，所以不能仅靠它初始化功能。代码改值用 `Set`；手动订阅的回调应保存句柄以便解除。`requiresRestart` 只用于启动时读取的配置。[完整示例](https://github.com/dragonpan2/probably-stolen-modding/blob/ae161038c6cfed6725f66cfbc5d6b05406975068/ModdingGuide.zh-CN.md#模组配置)

**检查场景**：全新存档、旧存档、切换存档、缺键、坏值、设置应用与重启、重复迁移。修改正式数据前先完成测试档验证。

## 普通 UI 与机器 UI

**窗口**：`CustomUIManager.Window(id,title,layer)` 开始构建；`Show()` 返回 `CustomUIWindow`，`GetWindow()` 返回隐藏窗口。先确认管理器存在，控件传 ID，之后用句柄更新。Close 会销毁并注销；Hide 只是隐藏。场景窗口随场景销毁，旧句柄不能当永久对象。[窗口及控件](https://github.com/dragonpan2/probably-stolen-modding/blob/ae161038c6cfed6725f66cfbc5d6b05406975068/ModdingGuide.zh-CN.md#自定义-ui)

**机器**：`MachineHelper.CreateMachineryWindow(canMove, panels)` 返回 `PixelWindow`，`item.SetContentWindow(window)` 接入；`Panel / PowerPanel` 组织面板，`GetBodyStorage(item,i)` 获取主体物品栏。面板数组顺序对应存档槽位；发布后只追加，视觉重排使用官方 `displayOrder` 重载。[机器完整示例](https://github.com/dragonpan2/probably-stolen-modding/blob/ae161038c6cfed6725f66cfbc5d6b05406975068/ModdingGuide.zh-CN.md#机器窗口)

**检查场景**：打开关闭多次、读档重建、输入中刷新列表、Escape 冲突、不同分辨率、机器旧档物品位置。UI 提示条件与实际提交校验须一致。

## 人脉升级

**注册**：`ModHelper.AddNetworkUpgrade` 的示例参数包括 modId、升级 ID、cost、subtitle、title、description、onUnlock，以及可选 prerequisites、cooldownDays、iconKey、tab；在 Init 或 OnEnable 注册。[完整示例](https://github.com/dragonpan2/probably-stolen-modding/blob/ae161038c6cfed6725f66cfbc5d6b05406975068/ModdingGuide.zh-CN.md#人脉升级)

**查询与清理**：`IsNetworkUpgradeUnlocked(id)` 读购买状态，`GetNetworkUpgrade(id)` 读本局副本；`RemoveNetworkUpgrades(modId)` 移除展示，保留存档状态。

**重要约束**：onUnlock 在官方付款之后执行，不再扣款。读档不会靠重新购买恢复你的内存标记，应查询已购状态；重复升级每次购买都可能触发回调。回调前需要可执行的准备，不把异常当成功交付。

**检查场景**：首次购买、钱与人情不足、旧档已购买、冷却后再次使用、依赖 ID 不存在。

## 开局方案、天赋与难度

| 功能 | 注册 | 查询 | 清理与时机 |
| --- | --- | --- | --- |
| 起始方案 | AddStartingScenario(modId,id,title,description,startWith,onStart,...) | GetStartingScenarioId / IsStartingScenario | RemoveStartingScenarios；onStart 只在新开局运行，读档不运行 |
| 起始天赋 | AddStartingPerk(modId,id,cost,type,name,description,...) | IsStartingPerkActive / GetStartingPerkIds | RemoveStartingPerks；效果由 Mod 实现，新开局和读档均恢复状态 |
| 难度 | AddDifficulty(modId,id,order,title,subtitle,configure,...) | GetDifficultyId / GetDifficultyRules / IsDifficultyAtLeast | RemoveDifficulties；OnDifficultyApplied 新开局及读档触发 |

表中方法均在 ModHelper 上，省略号表示还有参数，不能作为可编译声明复制。原始示例：[方案](https://github.com/dragonpan2/probably-stolen-modding/blob/ae161038c6cfed6725f66cfbc5d6b05406975068/ModdingGuide.zh-CN.md#起始方案)、[天赋](https://github.com/dragonpan2/probably-stolen-modding/blob/ae161038c6cfed6725f66cfbc5d6b05406975068/ModdingGuide.zh-CN.md#起始天赋)、[难度](https://github.com/dragonpan2/probably-stolen-modding/blob/ae161038c6cfed6725f66cfbc5d6b05406975068/ModdingGuide.zh-CN.md#难度)。注册定义通常在 Init/OnEnable；不要把效果施加与注册混为一件事。

`ModifyDifficulty` 修改共享定义，其他 Mod 能看到同一变化。恢复内存状态应以存档查询为准；发物品、发钱等一次性效果不能在每次读档重发。测试新开局与旧档分别执行，检查卸载或缺失 Mod 的回退行为。

## 夜间地点与事件

`AddAfterhourLocation` 返回 `DelegateAfterhourLocation`；示例字段包含 title、imageKey、backgroundKey、isDiscovered、onArrive、buildPanel。`isDiscovered` 决定显示，`isAvailable` 决定能否进入；onArrive/onLeave 在黑屏流程中运行，不重复打开或关闭游戏已管理的背包。[完整说明](https://github.com/dragonpan2/probably-stolen-modding/blob/ae161038c6cfed6725f66cfbc5d6b05406975068/ModdingGuide.zh-CN.md#夜间地点)

`GetAfterhourLocation(id)` 未知 ID 返回 null；`GetAfterhourVisits` 和 `Get/SetAfterhourCounter` 按局保存。`AddAfterhourEvent` 注册，`StartAfterhourEvent` 启动或延长，`EndAfterhourEvent` 结束；对应 RemoveAfterhourLocations / RemoveAfterhourEvents 清理注册。onTick 每帧调用，避免重扫描或重复生成资源。

检查：发现/不可用状态、进入/返回、回调失败、存档重载、事件延长/结束、多事件叠加。

## 鉴定物品

`ModHelper.AddAppraisalItem(modId,id,itemId,unlockRank,createRandom,getCorrectValue,guideItemId,...)` 注册类型；`RemoveAppraisalItems(modId)` 移除，`GetAppraiserRank()` 查询等级。[完整示例](https://github.com/dragonpan2/probably-stolen-modding/blob/ae161038c6cfed6725f66cfbc5d6b05406975068/ModdingGuide.zh-CN.md#鉴定物品)

createRandom 构造物品并保存随机数值，使用 `AppraisalHelper.InitAppraisalItem` 初始化鉴定属性；getCorrectValue 从物品状态读取稳定结果，不能每次估价重新随机。默认 isType 按 itemId 判断，变体 ID 须提供匹配函数。替换原版条目后，移除注册要到重启才恢复原版。

检查：随机生成后多次估价一致、保存重载一致、等级解锁与指南发放、变体识别、卸载后的行为。

## 跨 Mod 与后台工作

硬依赖写 Prerequisites 并引用前置 Mod DLL，不复制其 DLL；缺少前置 Mod 的警告不保证硬引用可加载。松耦合用 Expose/Lookup 或 OnMessage/OffMessage/SendMessage；Lookup 允许 null，能力不满足也可能拒绝。订阅用具名处理函数或保存委托，清理时用同一引用。[联动](https://github.com/dragonpan2/probably-stolen-modding/blob/ae161038c6cfed6725f66cfbc5d6b05406975068/ModdingGuide.zh-CN.md#依赖另一个模组)

后台使用 `ModHelper.RunInBackground` 并响应取消，Unity 对象操作回主线程；`StartCoroutine / StopCoroutine` 按 Mod ID 管理。停止时回调可能被丢弃，不把“工作已启动”当“效果已提交”。Delay 仅用于确实需要等待时间的行为，不能证明资源或存档就绪。[后台](https://github.com/dragonpan2/probably-stolen-modding/blob/ae161038c6cfed6725f66cfbc5d6b05406975068/ModdingGuide.zh-CN.md#后台工作)

## 发布前接口检查

官方原文中的匿名事件订阅用于简洁演示；实际工程若需要解除订阅应保存委托或使用具名方法。游戏已自动应用 HarmonyPatch，不重复 PatchAll；手动补丁只撤销自己的 ID。能力必须与调用匹配，开发者模式不是发布扫描证据。使用 F8 的 `mod-scan <Mod ID>`；记录目标游戏版本、拒绝项、待生效发现和指纹。未来能力政策以当前目标版本和官方更新记录复核。
